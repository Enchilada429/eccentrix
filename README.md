The game will be made as a **2D URP** project using the **Unity** game engine.
<br>
Game assets such character pixel art or level backgrounds can be made in **any tool or software** of the member's choice.

## Welcome to Eccentrix
Eccentrix's main theme is to be a **platform-based fighting** game with an **anime pixel-art** style.
<br>
This game will contain a handful of levels as well as characters to play as. Primarily aimed for **online gameplay** but in the future will include an optional singleplayer mode against AIs.
<br><br>
The playable characters in Eccentrix will have a range of attack and movement options based on their specialty. The <span style="color:lightgreen">**base**</span> character is expected to have the following functionality:
<ol style="color:lightgreen">
    <li>Ground WASD Attacks</li>
    <li>Aerial WASD Attacks</li>
    <li>Strong Attacks</li>
    <li>Special/Combo Ground Attacks</li>
    <li>Special/Combo Aerial Attacks</li>
    <li>WASD Run + Walk Movement</li>
    <li>Dodges</li>
    <li>Counters</li>
</ol>
<br>
The platforms are intended to be contained within a <span style="font-weight:bold">1920 x 1080</span> screen dimensions as standard with most games.
